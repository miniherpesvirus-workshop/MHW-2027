# Rotterdam photo

`rotterdam.png` is the organiser-supplied Rotterdam collage, included unchanged
at its original 2048 × 819 pixels. The page already uses this image.

To replace it later, update the image `src`, `alt`, `width` and `height` in the
root `index.html`, and adjust the `.city-figure` CSS aspect ratio to match.
Add any required photographer / licence credit at the `PHOTO CREDIT` comment.
